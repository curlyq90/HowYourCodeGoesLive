THE WHOLE LOOP

Know what you’re saying yes to.

Branch → worktree (optional) → edit → commit → push → pull request → checks → preview → merge → live.

Before approving your next AI-generated change, ask:

  • What changed? Show me the diff and explain why.
  • What did we verify? Show me the checks and the working preview.
  • What happens when we ship? Confirm the environment, data changes, and recovery plan.
